`offline` reloads until the service worker controls the page, drops any cached path containing `uncache`, clears the browser's HTTP cache so only the service worker can answer, then cuts the network, as `offline-nav` (/ to /jobs to /settings) and `offline-uncached` (a route whose chunk is gone shows "Can't reach Conveyor") do. With `only: "editor"` it leaves the network up and instead aborts just the chunks `--root`'s build lists in `editor-chunks.json`, as if they failed to download. Every `offline` step starts recording non-GET `/api/` requests for `unsent`. `profile-editor-offline` uses all of these: it serves the profile as edited so Reset shows, requires Tidy, Save and Reset to be disabled, pokes each, presses Ctrl S, and then needs no dialog open and no write sent.
