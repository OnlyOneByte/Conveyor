`offline` reloads until the service worker controls the page, drops any cached path containing `uncache`, clears the browser's HTTP cache so only the service worker can answer, then cuts the network, as `offline-nav` (/ to /jobs to /settings) and `offline-uncached` (a route whose chunk is gone shows "Can't reach Conveyor") do. With `only: "editor"` it leaves the network up and instead aborts just the chunks `--root`'s build lists in `editor-chunks.json`, as if they failed to download. Every `offline` step starts recording non-GET `/api/` requests for `unsent`. `profile-editor-offline` uses all of these: it serves the profile as edited, requires the "You're offline" notice with Try again in place of the editor frame and no Tidy, Save or Reset at all, presses Ctrl S and Try again, and then needs no dialog open and no write sent.
