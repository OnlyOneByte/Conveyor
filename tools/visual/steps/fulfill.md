`fulfill` answers every request to a URL glob, or only those with its `method`, with a fixed status and JSON body for the rest of the scene, after `delayMs` if it's set, as `retry-link` does to get an already-retried 409 without changing the seeded jobs. With `times` it answers only that many requests and then falls through to the next match, so a scene can stub a list before and after a change: the `settings-delete-focus-*` scenes answer the profile list once with the doomed row and then without it, confirm the delete from the keyboard, and assert where focus lands: the next row for a first or middle row, the previous row for the last, Add profile for the only one.
