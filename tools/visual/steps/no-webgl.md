`noWebgl` makes every canvas refuse a WebGL context, the way a browser with hardware acceleration turned off does, then reloads the page. Canvases still give a 2D context. `make-no-webgl` uses it to show that Make keeps its form and puts a still placeholder where the 3D preview goes. With `noWebgl: "after-probe"` the first WebGL request still gets a context and every later one is refused, so the app's WebGL check passes and the 3D renderer then fails to start, as on a blocklisted GPU; `make-renderer-fails` and `job-renderer-fails` use it to show the same placeholder instead of an error page.
