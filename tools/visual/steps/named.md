`named` fails unless its target's accessible name contains the text it shows, the check axe's `label-content-name-mismatch` rule makes for WCAG 2.5.3 (Label in Name). The name is the `aria-label` when there is one, else the visible text, and both are compared the way axe does: ignoring case, punctuation and runs of whitespace. `printers-edit-lazy`, `first-run-add-lazy` and `printers-dialog-lazy` use it on each button while it shows "Opening…", so a pending button can't keep a label like "Edit Voron" that no longer matches what's on screen.
