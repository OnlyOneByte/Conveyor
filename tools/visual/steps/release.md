`release` lets go of every request a `stall` step for the same glob is holding. It fails if no `stall` names that glob, or if no request ever reached it, so a glob that matches nothing can't pass by accident. The `loading-*` scenes use it once their skeleton has been checked. With `fail: true` every held request fails instead of going through, as `printers-edit-spam-down` and `first-run-add-spam-down` do to fail the printer form's load only after Enter has been pressed five times on the pending button.
